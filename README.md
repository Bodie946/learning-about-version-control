# Learning about Version Control

Author: Yichuan Li

Solving merge conflicts takes conscious effort, but I can do it!

What I like about version control is that it allows people for different parts of the world work together and tracks what contributions each person has done in a open sourced way.

What I find challenging is sometimes where you have a large rp it might be hard to navigate to the very specific version or edit you would want to revise to.
